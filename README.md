# AnkiLocal - プライベート版Anki Webアプリケーション

Ankiのエクスポートテキスト（タブ区切り）ファイルを使用して、セキュリティの保護されたWeb環境で学習ができるローカル動作型のWebアプリケーションです。

## 特長
- **セキュアなオフライン動作**: すべてのデータはPC内のローカルSQLiteデータベースに保管され、ネットワーク外部に送信されることはありません。
- **トークン認証による簡易アクセス制限**: サーバー起動時に自動生成されるランダムなセキュリティトークンをURLに付与した者だけがアクセスできます。
- **多様なノートタイプ対応**: Basic、Basic (optional reversed card)（表裏逆転カード自動生成）、および Cloze（多重穴埋め対応）に対応しています。
- **SM-2 アルゴリズムに基づく間隔反復**: Ankiと同様に「Again / Hard / Good / Easy」の4段階ボタンによる学習スケジュールが可能です。
- **ガラスモーフィズムダークモードUI**: 美しくインタラクティブなUIで学習体験を向上します。

## ディレクトリ構成
```text
/
├── backend/                  # FastAPIバックエンド
│   ├── main.py               # エントリーポイント
│   ├── config.py             # 設定（SSOT）
│   ├── database.py           # SQLite非同期接続
│   ├── parser.py             # デッキパーサー
│   ├── srs.py                # 忘却曲線アルゴリズム
│   └── routers/              # APIルーター
├── frontend/                 # Vanilla HTML/CSS/JS フロントエンド
│   ├── index.html            # メインHTML
│   ├── css/                  # 各種スタイルシート
│   └── js/                   # 構成モジュール＆定数
├── docs/                     # 開発規約ドキュメント
├── start.bat                 # Windows向け一発起動スクリプト
└── README.md                 # 本ファイル
```

## クイックスタート (Windows)

1. **起動**:
   リポジトリ直下の `start.bat` をダブルクリックします。必要なPython環境構築、依存ライブラリのインストール、サーバー起動が自動で進行します。

2. **アクセス**:
   起動すると、黒いコマンドプロンプト画面（AnkiLocal Server）が立ち上がり、以下のようなURLが表示されます。
   `http://127.0.0.1:8000/?token=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`
   これをコピーし、お好みのブラウザ（Chrome, Edgeなど）で開きます。

3. **デッキのインポート**:
   「インポート」タブを開き、Ankiからエクスポートしたデッキテキストファイル（例: `Sample.Deck\すべてのデッキ.txt`）をドラッグ＆ドロップまたは選択してアップロードします。

4. **学習開始**:
   「デッキ」タブに登録されたデッキとカード数が表示されます。「学習開始」をクリックして、問題の裏表や穴埋めクイズを繰り返します。
